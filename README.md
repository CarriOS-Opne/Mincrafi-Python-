# Minecraft: Python Edition 1.3

파이썬(ModernGL + pygame + numba)으로 만든 마인크래프트 스타일 게임입니다.
`iEmreM/Minecraft-Clone` 엔진(무한 지형, 26개 바이옴, 마을, 677가지 블록) 위에
타이틀 화면, 월드 저장, 서바이벌 모드, 낮/밤, 한국어 메뉴를 얹었습니다.

> 비공식 팬 메이드 프로젝트입니다. Mojang/Microsoft와 관계없습니다.

## 실행

**Windows:** `실행.bat` 더블클릭 (처음엔 필요한 패키지를 자동 설치)

**직접 실행:**
```
pip install -r requirements.txt
python main.py
```

처음 실행할 때 numba가 지형 생성 코드를 컴파일하느라 창이 뜨기까지 30초~1분 정도
걸릴 수 있어요. 두 번째부터는 캐시 덕분에 빠릅니다.

## 1.3에서 바뀐 것

- **떨어지는 아이템** — 서바이벌에서 블록을 캐거나 동물을 잡으면 아이템이 튀어나와 바닥에 떨어지고, 빙글빙글 돌다가
  가까이 가면 빨려 들어옴 (같은 아이템끼리 합쳐짐, 5분 지나면 사라짐)
- **아이템** — 막대기, 석탄, 철·금·구리·네더라이트 주괴, 다이아몬드, 네더라이트 파편, 날 돼지고기·익힌 돼지고기·구운 감자·썩은 살점
- **곡괭이·검** — 나무·돌·구리·철·다이아몬드·네더라이트 6단계. 원작과 같은 채굴 속도와 등급
  (돌은 맨손 7.5초 → 나무 곡괭이 1.1초, 철광석은 돌 곡괭이 이상, 다이아는 철 곡괭이 이상, 흑요석·고대 잔해는 다이아 이상)
  맨손으로 캐면 돌 종류는 아무것도 안 떨어짐. 검은 공격력이 높음
- **픽셀 재활용** — 제공한 16×16 아이템 그림을 바탕으로, 없는 것은 같은 픽셀에 색만 바꿔 만듦:
  철 곡괭이·검 → 구리 곡괭이·검, 다이아 곡괭이·검 → 네더라이트, 철 주괴 → 구리·금·네더라이트 주괴,
  석탄 → 네더라이트 파편, 날 돼지고기 → 익힌 돼지고기, 곡괭이 손잡이 색 → 막대기
- **창백한 정원** — 회색 창백한 참나무 숲, 창백한 이끼 블록·카펫, 늘어진 창백한 이끼, 닫힌 눈꽃. 짙은 숲 절반이 창백한 정원이 됨
- **고대 잔해** — 기반암 바로 위에 아주 드물게. 화로에 구우면 네더라이트 파편
- **먹기** — 서바이벌에서 음식을 들고 오른쪽 클릭하면 체력 회복 (허기 시스템은 아직 없음)

### 새 제작법

| 재료 | 결과 |
| :--- | :--- |
| 판자 2개 (세로) | 막대기 4개 |
| 재료 3개 (위 줄) + 막대기 2개 (가운데 세로) | 곡괭이 (재료: 판자/조약돌/구리·철 주괴/다이아몬드) |
| 재료 2개 (세로) + 막대기 1개 | 검 |
| 석탄 위 + 막대기 아래 | 횃불 4개 |
| 네더라이트 파편 4 + 금 주괴 4 | 네더라이트 주괴 |
| 다이아 곡괭이/검 + 네더라이트 주괴 | 네더라이트 곡괭이/검 (대장장이 작업대 대신 제작대에서) |

화로: 철·금·구리 광석 → 주괴, 고대 잔해 → 네더라이트 파편, 날 돼지고기 → 익힌 돼지고기. 연료: 석탄 80초, 판자·원목 6초, 막대기 5초

## 1.2에서 바뀐 것

- **바이옴 색** — 잔디·풀·나뭇잎(참나무·정글·아카시아·짙은 참나무)·덩굴이 바이옴마다 원작 색으로, 경계는 부드럽게 섞임
  (사바나는 누런색, 정글은 진한 초록, 늪은 칙칙한 녹갈색, 짙은 숲은 어두운 초록 등). 가문비·자작나무 잎은 원작처럼 고정색
- **물** — 해수면보다 높은 곳의 물(밭 물길, 우물, 언덕의 연못)도 보이게
- **마을 (위키 기준)** — 밭은 원작 `plains_small_farm`처럼 참나무 원목 테두리 + 경작지 높이의 물길 + 밀, 큰 밭(13×9)도 생김, 퇴비통.
  평원 집 지붕은 벽돌 → 참나무, 벽 아래 한 줄은 조약돌, 실내는 횃불
- **인벤토리** — 블록이 정육면체로 보임. 크리에이티브 인벤토리를 제공한 `tab_inventory.png`로 새로 만듦
  (위아래 탭, 9×5 칸, 스크롤바, 휴지통, 검색). 핫바도 원작 모양
- **조작** — W 두 번 = 달리기, 크리에이티브에서 스페이스 두 번 = 날기/착지(땅에 닿으면 자동 착지), Shift = 웅크리기(천천히 걷기)

## 1.1에서 바뀐 것

- **로고·폰트·UI** — 타이틀에 새 로고, 한글 픽셀 폰트(갈무리11), 마인크래프트식 GUI 배율·버튼·흙 배경
- **그림자** — 해 방향 그림자 맵(설정에서 켜고 끌 수 있음), 햇빛 받는 면/그늘진 면 구분
- **해와 달 텍스처** — 달은 날마다 8단계로 모양이 바뀜
- **동물** — 돼지·소·닭·고양이가 풀밭에 생기고 돌아다님. 때리면 빨개지고 도망가요. 추운/더운 바이옴은 다른 색
- **제작** — 인벤토리 2×2, 제작대 3×3, 화로(모래→유리, 조약돌→돌 등)

### 제작법 (블록만 있는 게임이라 일부는 원작과 다름)

| 재료 | 결과 |
| :--- | :--- |
| 원목 1개 | 판자 4개 |
| 판자 2×2 | 제작대 |
| 조약돌 8개 (가운데 비움, 3×3) | 화로 |
| 돌 2×2 / 모래 2×2 / 점토 2×2 | 석재 벽돌 4 / 사암 / 벽돌 |

| 판자 2열×3행 | 참나무 문 3 · 판자 H모양 → 사다리 3 |

화로 연료: 판자, 원목, 석탄 광석, 제작대 등

## 무엇이 있나

- **타이틀 화면** — 실제 월드를 천천히 도는 파노라마, 블록으로 쌓은 로고, 노란 스플래시 문구
- **월드 선택 / 만들기** — 이름, 시드(숫자·글자 모두 가능, 비우면 무작위), 게임 모드
- **월드 저장** — `saves/월드이름/`에 저장. 2분마다 자동 저장, 메뉴로 나갈 때·창을 닫을 때도 저장
- **서바이벌 모드**
  - 체력 하트 10칸, 낙하 데미지(3칸 넘게 떨어지면), 익사(공기방울 10개), 사망·리스폰
  - 블록마다 캐는 시간이 다름(흙 0.5초, 돌 1.8초, 흑요석 6초, 기반암 불가)
  - 캔 블록이 인벤토리로 들어옴 (돌 → 조약돌, 잔디 → 흙, 나뭇잎은 가끔 묘목)
  - 놓으면 개수가 줄어듦, `E` 인벤토리(36칸)에서 스택 옮기기
- **크리에이티브 모드** — 비행, 즉시 파괴, `E`로 677개 블록 선택창, 휠 클릭으로 블록 집기
- **낮/밤** — 20분에 하루, 해돋이·노을, 밤하늘의 별, 네모난 해와 달
- **수영** — 물속에서 천천히 가라앉고 스페이스로 헤엄쳐 올라감, 물속은 파랗게
- **설정** — 렌더 거리, 시야(FOV), 마우스 감도, 그림자, 동물, 낮/밤 주기, FPS 표시 (`options.json`에 저장)

## 조작

| 동작 | 키 |
| :--- | :--- |
| 이동 | `W` `A` `S` `D` |
| 점프 / 헤엄쳐 오르기 / 위로 날기 | `Space` (누르고 있기) |
| 달리기 | `W` 두 번 빠르게 (또는 `Ctrl`) |
| 웅크리기 (천천히 걷기) / 아래로 날기 | `Shift` |

| 블록 캐기 | 왼쪽 클릭 (누르고 있기) |
| 블록 놓기 / 제작대·화로 열기 | 오른쪽 클릭 |
| 동물 때리기 | 왼쪽 클릭 |
| 블록 집기 (크리에이티브) | 휠 클릭 |
| 핫바 선택 | `1`–`9`, 마우스 휠 |
| 인벤토리 (크리에이티브는 블록 선택창) | `E` |
| 게임 메뉴 (일시정지) | `Esc` |
| 채팅 / 명령어 | `T`, `/` |
| HUD 숨기기 | `F1` |
| 스크린샷 (`screenshots/`) | `F2` |
| 디버그 화면 | `F3` |
| 렌더 거리 | `+` / `-` |

## 명령어

| 명령어 | 설명 |
| :--- | :--- |
| `/gamemode survival` · `/gamemode creative` | 게임 모드 바꾸기 (`/gm s`, `/gm c`도 됨) |
| `/time set day` · `night` · `noon` · `midnight` · 숫자 | 시간 바꾸기 (하루 = 24000) |
| `/give <블록 이름> [개수]` | 블록 받기 — 예: `/give oak log 32` |
| `/tp <x> [y] <z>` | 순간이동 (`~` 상대 좌표 가능) |
| `/locate <바이옴 또는 village>` | 가장 가까운 바이옴·마을로 이동 |
| `/biome` · `/seed` | 지금 바이옴 / 월드 시드 |
| `/spawnpoint` | 지금 위치를 리스폰 지점으로 |
| `/kill` | 리스폰 (서바이벌) |
| `/set` | 렌더 거리·와이어프레임 등 설정 |
| `/help` | 전체 목록 |

`/` 없이 입력하면 채팅처럼 화면에 남습니다.

## 폴더 구조

```text
main.py              App(창·메뉴·옵션) + Session(열린 월드 하나)
commands.py          콘솔 명령어
game/
  ui.py              타이틀·월드 선택·설정·일시정지·사망·인벤토리 화면
  survival.py        채굴 시간, 드롭, 인벤토리, 체력·공기
  crafting.py        제작법·화로
  save.py            월드 저장/불러오기, options.json
engine/
  renderer.py        ModernGL 렌더러 (+ 낮/밤, FOV)
  camera.py          플레이어 물리 (+ 수영, 낙하 추적)
  hud.py             핫바, 크리에이티브 블록 선택창, F3, 콘솔
  overlay.py         pygame으로 그린 2D 화면을 GL에 올리는 레이어
  entities.py        동물 모델·움직임·충돌
  fonts.py           한글 폰트 찾기 (맑은 고딕 등)
world/               지형 생성(+시드), 청크, 메시, 블록 목록
shaders/             GLSL (하늘·그림자·동물)
assets/              로고, 폰트, 해·달, 동물, GUI 텍스처
saves/               월드 (처음 저장할 때 생김)
```

## 시드는 어떻게 동작하나

지형 노이즈 코드는 numba로 미리 컴파일되어 있어서 순열표를 시드마다 바꾸면 매번 재컴파일해야
합니다. 그래서 시드는 "하나의 무한한 세계 안에서 어디에 사는지"를 정합니다 — 4096블록 단위로
세계를 통째로 옮겨서 대륙·바이옴·강·마을이 전부 달라집니다(약 14,600가지).
